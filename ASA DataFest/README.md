# ASA DATAFEST: PATIENT'S WAIT TIME 🏦

## By Robin Nguyen ☀️

## Introduction
This project analyzes the factors that impact patient's wait time (days between each visit) in an anonymous healthcare system in Kansas.

Data is collected to support the ASA DataFest at Loyoloa Chicago University.

Since ASA Datafest 2026 is still going on for other regions, I will not showcase the specific data and analyzing code here. However you can access or team presentation [Here](https://docs.google.com/presentation/d/1575E_rwGa1d-xeZCK15iPO9d3algdql-AXXL5bj-w-k/edit?usp=sharing)

Detailed process and key findings will be updated after ASA Datafest 2026 ends.
